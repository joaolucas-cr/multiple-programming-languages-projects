x BR01	The system must allow users to add new books with a unique ID, title, author, and publication year.


x BR02	Users must be able to search for books by title, author, or ID.

x BR03	The system must allow registration of library members with unique IDs.

x BR04	Registered members must be able to borrow available books.

x BR05	Members must be able to return books they have borrowed.

x BR06	A book cannot be borrowed if it is already checked out.

x BR07	Each member can borrow a maximum of 3 books simultaneously.

x BR08	The system must display all available books and currently borrowed books.

x BR09	Books, members, and borrowing records must be saved to files for persistence.

x BR10	The system must automatically load saved data when the application starts.
